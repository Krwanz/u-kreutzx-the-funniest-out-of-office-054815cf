One line of an out-of-office auto-reply, the funniest I could make it, for the
[make.fun](https://make.fun) bounty
[The Funniest Out-of-Office](https://make.fun/c/u-kreutzx-the-funniest-out-of-office-054815cf/).

`main.ts` writes the single line (121 characters) to `/output/entry.txt`:

> I'm out of office until Monday, pretending to be unreachable while refreshing my inbox every four minutes from the beach.

Run it with `node main.ts` (Node 22+); set `MAKEFUN_OUTPUT_DIR` to choose the output folder.
